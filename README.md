谐音键盘是一款完全离线运行的安卓中文拼音输入法，适合在聊天、评论和日常输入时使用自定义同音词、常用语录与趣味评论编码。

## 主要功能

### 中文拼音输入

- 内置约 6.5 万条离线简体中文拼音词库。
- 支持长拼音自动分词组句和横向候选词选择。
- 支持中英文切换、数字面板、常用符号和上滑快捷字符。
- 候选词学习记录仅保存在本机。

### 同音替换

用户可以建立“原词 → 同音替换词”规则。中文候选上屏后，输入法会自动检查并替换匹配内容。

- 支持总开关。
- 每条规则可以单独启用或停用。
- 优先匹配较长词语，避免短词破坏完整词组。

### 评论模式

评论模式会把上屏文字编码成由 `[赞]`、`[爱心]`、`[玫瑰]`、`[鼓掌]` 四种完整 token 组成的内容。

编码采用 UTF-8 可逆格式，中文、英文、数字、标点、空格、换行和 emoji 均可还原。复制包含评论密文的内容后，点击键盘工具栏中的“解码剪贴板”，输入法会忽略普通中文、数字和标点，只提取完整 token 并将解码后的明文上屏。

### 常用语录

可以按照聊天场景建立语录分组，并从键盘工具栏快速选择和上屏。语录及分组全部保存在本机。

## 安装与启用

1. 从本仓库 Releases 页面下载 `HomophoneKeyboard-v2.0.0-release.apk`。
2. 在手机上打开 APK，并按照系统提示允许当前浏览器或文件管理器安装未知来源应用。
3. 安装后打开“谐音键盘”。
4. 阅读首次启动的免费使用声明，勾选“我知道了”并确认。
5. 点击“启用输入法”，在 Android 系统设置中打开“谐音键盘”。
6. 返回应用，点击“选择‘谐音键盘’”，将其设为当前输入法。

包名为 `com.xieyin.app`。它无法覆盖早期使用其他包名的版本，旧版规则、语录和设置也不会自动迁移。

## 基本使用

1. 保持键盘处于中文模式，输入拼音。
2. 点击候选词，或按空格选择第一个候选词。
3. 需要英文时，点击底部的“中/英”切换按钮。
4. 拼音中的 `ü` 使用字母 `v` 输入。
5. 在应用首页添加同音替换规则，并通过“启用替换”控制是否生效。
6. 在键盘工具栏中切换评论模式、打开语录或解码剪贴板。
